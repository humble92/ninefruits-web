Ninefruits for Laravel

A student information system a university can install and run. It carries academic work from an admission application through records, registration, grades, and graduation.

code View source

Purpose

Give one campus a single system for the academic year: staff work in an admin panel, and students, instructors, and applicants use a portal. Screens and manuals are in Korean, English, Chinese, and Lao, so the same installation can serve more than one language.

Technology stack

PHP 8.5 Laravel 13 Filament 5 Livewire 4 PostgreSQL 18 Redis Horizon Gotenberg Fortify Docker

Filament is the admin panel. Livewire is the portal. PostgreSQL holds row-level security and the audit trail. Redis and Horizon run the queue. Gotenberg renders PDFs. Fortify handles sign-in and two-factor authentication. Local demo installs run with Docker.

Features

switch_account

Admin and portal

Staff run records, admissions, certificates, exams, graduation, and reports in the admin panel. Students, instructors, and applicants use the portal. One account can hold more than one role.

badge

People, records, admissions

People stay separate from student records. Status changes such as leave, return, and withdrawal go through request and approval. Admission rounds collect applications and open a record for admitted students.

calendar_month

Curriculum and registration

Course versions, prerequisites, graduation requirements, sections, and timetables. Registration applies credit limits, capacity, waitlists, and holds.

grading

Grades and course evaluation

Absolute and relative grading, distribution caps, submission, finalization, and grade-change approval. Course evaluation is anonymous, and grade viewing can wait until the evaluation is done.

verified

Certificates, exams, graduation

Certificate PDFs with a public QR check. Language and comprehensive exams. Attendance from the timetable. A graduation audit, waivers, and degree numbers.

lock

Access and audit

Shared sign-in, app and email two-factor authentication, roles scoped to an org unit, an activity audit, row-level security, and encrypted personal data. Reports export to CSV, and an LMS link can sync courses and draft scores.

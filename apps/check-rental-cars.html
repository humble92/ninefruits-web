Departure

A condition report for a rental car, made at pickup. Walk around the car, photograph each side, and keep the PDF and the original photos before you drive away.

Purpose

Help a renter notice and record damage that is already on the car. If the company later charges for a mark, the pickup photo and the report are there to point at. The AI describes what is visible in each photo. It does not decide when the damage happened or who caused it.

Technology stack

Python FastAPI Uvicorn Jinja2 SQLite Pillow ReportLab Meta Model API

The page is server-rendered and uses no third-party scripts. A background worker analyzes each photo, checks the structured response, and builds the PDF. SQLite keeps the job, and originals stay on disk with a hash. The default model is muse-spark in Contributor mode. muse-ember is available in Standard mode, where Meta does not use the content for training. Email is optional SMTP.

Features

photo_camera

A guided walk-around

Twelve views cover the front, rear, corners, and sides. Extra photos can show wheels, glass, or a close-up. A partial set is allowed, and the report lists the views that are missing.

frame_inspect

AI review of the photos

Each photo is checked for scratches, dents, and other marks. Findings keep the evidence photo, an optional numbered box, and a note when the model is unsure. Notes you type stay separate from the AI observations.

picture_as_pdf

A report you can keep

The HTML page and the PDF say the same thing. Original photos download as a ZIP. Email can send the PDF, or a link when the file is large. JPEG, PNG, WebP, and HEIC uploads are accepted.

lock

No account, short retention

There is no sign-in. The browser that created the draft can edit it and send email. A shared link can only read the report. Server copies expire after seven days. Contributor mode tells you that Meta may use the photos for training before analysis starts.
